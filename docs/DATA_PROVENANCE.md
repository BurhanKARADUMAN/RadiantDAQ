# Data provenance and scientific status

- `examples/demo/*.csv`, `examples/demo/*.png`, and `examples/demo/summary.json` were generated by the committed Python models using NumPy random generators, not by a laboratory instrument, clinical device, or Geant4/GATE radiation-transport application.
- The example run is reproducible with `radiantdaq demo --events 1600 --seed 2026 --out examples/demo` and `radiantdaq sweep --events 1100 --seed 2026 --out examples/demo`.
- Output reports store the complete default configuration and a seed, but the published CSV/PNG may change slightly across numerical library versions due to random-number or rendering differences.
- The generated figures show synthetic distributions. The reported Gaussian-equivalent CTR is **not** a measured FWHM of a physical electronic output pulse.
- No user-provided raw PET measurements, SiPM current waveforms, or GATE optical simulation files were available for this initial project milestone.
