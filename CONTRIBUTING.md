# Contributing

Contributions are welcome in model validation, waveform reconstruction, statistical uncertainty, detector geometry, Geant4/GATE, and data analysis.

- Keep synthetic and experimental data clearly separated.
- Never label a toy model output as measured detector CTR or energy resolution.
- New model features should include unit tests and explain their assumptions.
- Include numerical seeds, calibration method, units, and device provenance in results.
- Do not include sensitive, proprietary or personal clinical data.
